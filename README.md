# Qラーニング迷路教材

迷路ゲームを題材に、Qラーニングの仕組みと学習結果を視覚的に確認できる教材です。プレイヤーを手動で操作できる「迷路ゲーム」と、報酬を設定して方策を学習する「Qラーニング」の2つのアプリで構成されています。

Qラーニング側では、学習中の評価エピソードを迷路ゲームへ送信して動きを表示できるほか、学習後にQ値・獲得経路・訪問頻度を画像で確認できます。

## 1. 主な機能

- 矢印キーまたはマウスクリックで遊べる迷路ゲーム
- ステップ、壁、食べ物、罠、エネルギー切れの報酬を変更可能
- ε-greedy法を使ったQラーニング
- 学習の進捗表示と途中停止
- 学習結果を3種類の画像で可視化
  - `q_table.png`：各マスの上下左右のQ値
  - `route.png`：学習した方策による経路
  - `visitation_heatmap.png`：各マスの訪問頻度
- ローカルHTTP APIによる迷路状態の取得・移動・リセット
- Pythonをインストールせずに起動できるWindows向け実行ファイルを同梱

## 2. 必要環境

### 実行ファイルを使う場合

- Windows

### Pythonから実行する場合

- Windows
- Python 3.10以降
- Tkinter（通常のWindows版Pythonに同梱）
- Pillow 10.0以降

> [!NOTE]
> 迷路ゲームは効果音の再生にWindows標準の`winsound`を使用しているため、現在のソースコードはWindows向けです。

## 3. 実行方法

### 3.1. 実行ファイルから起動する

次の2つをそれぞれ起動します。

```text
迷路ゲーム\迷路ゲーム.exe
Qラーニング\Qラーニング.exe
```

学習の様子を迷路ゲームに表示する場合は、先に迷路ゲーム側のHTTPサーバーを設定してください。設定方法は「5. Qラーニングを実行する」を参照してください。

### 3.2. Pythonから起動する

PowerShellでこのREADMEがあるディレクトリへ移動し、依存パッケージをインストールします。

```powershell
python -m pip install -r .\Qラーニング\requirements.txt
```

2つのPowerShellウィンドウを開き、それぞれ次のコマンドを実行します。

迷路ゲーム：

```powershell
python .\迷路ゲーム\maze.py
```

Qラーニング：

```powershell
python .\Qラーニング\learner.py
```

## 4. 迷路ゲームの遊び方

- 矢印キー、または隣接するマスのクリックでプレイヤーを移動します。
- 食べ物に到達するとクリアです。
- 罠を踏むか、残りエネルギーが0以下になるとゲームオーバーです。
- 通路を1マス移動するとエネルギーを1消費します。
- 壁へ移動しようとするとエネルギーを5消費し、その場に留まります。
- `F5`キーまたは「マップ再読込」ボタンで最初からやり直せます。

初期エネルギーは20です。画面には残りエネルギー、累計報酬、移動ログが表示されます。

## 5. Qラーニングを実行する

### 5.1. 迷路ゲームを準備する

学習中の評価エピソードを迷路ゲームに表示する場合は、迷路ゲームの「HTTP設定」タブで次の操作を行います。

1. 「リモートプレイを許可」にチェックを入れます。
2. ホストが`127.0.0.1`、ポートが`8000`であることを確認します。
3. HTTPアクセス欄の「開始」ボタンを押します。

異なるホストやポートを使用する場合は、Qラーニング側の接続先URLも同じ値に変更してください。

### 5.2. 学習を開始する

Qラーニングの「訓練・接続設定」タブで、訓練エピソード数と各報酬を入力して「開始」を押します。

| 設定 | 初期値 | 意味 |
|---|---:|---|
| 訓練エピソード数 | 10000 | 学習を繰り返す回数 |
| 移動報酬 | -1 | 通路を1マス進んだときの報酬 |
| 壁の報酬 | -5 | 壁に衝突したときの報酬 |
| 食べ物の報酬 | 30 | 食べ物へ到達したときの報酬 |
| 罠の報酬 | -30 | 罠へ入ったときの報酬 |
| エネルギー切れの報酬 | -100 | エネルギーがなくなったときの報酬 |

「評価エピソードを迷路ゲームに表示する」のチェックを外すと、迷路ゲームを起動せずに学習できます。チェックを入れた場合、100エピソードごと、および最後のエピソードの動きが迷路ゲームに表示されます。

学習が終わると、「Qテーブル」「経路」「訪問ヒートマップ」の各タブに結果が表示されます。画像は拡大・縮小・全体表示が可能です。

> [!IMPORTANT]
> 生成されたPNG画像は`Qラーニング`フォルダーに保存されますが、Qラーニングアプリを閉じると自動的に削除されます。残したい画像は、アプリを閉じる前に別の場所へコピーしてください。

## 6. 学習の設定を変更する

詳細な学習パラメータは[`Qラーニング/learner.py`](Qラーニング/learner.py)の先頭付近にあります。

```python
LEARNING_RATE = 0.10
DISCOUNT_FACTOR = 0.95
EPSILON_START = 1.0
EPSILON_END = 0.02
EPSILON_DECAY = 0.9995
MAX_STEPS_PER_EPISODE = 100
RANDOM_SEED = 8
```

- `LEARNING_RATE`：新しく得た情報をQ値へ反映する割合
- `DISCOUNT_FACTOR`：将来得られる報酬をどの程度重視するか
- `EPSILON_START` / `EPSILON_END`：ランダムな行動を選ぶ確率の開始値と下限
- `EPSILON_DECAY`：エピソードごとに探索率を減らす割合
- `MAX_STEPS_PER_EPISODE`：1エピソードで許可する最大行動数
- `RANDOM_SEED`：結果を再現しやすくするための乱数シード

表示間隔と表示速度も同じ場所で変更できます。

```python
SHOW_EVERY_EPISODES = 100
MOVE_DELAY = 0.08
```

## 7. マップの編集

両方のアプリは、それぞれのフォルダー内にある`map.txt`を読み込みます。連携して使用するときは、次の2ファイルを同じ内容にしてください。

- `迷路ゲーム/map.txt`
- `Qラーニング/map.txt`

マップは同じ文字数の行で構成された長方形にし、外周をすべて壁`#`で閉じます。プレイヤー`P`は必ず1つだけ配置してください。

| 記号 | 意味 | 画像ファイル |
|:---:|---|---|
| `#` | 壁 | `wall.png` |
| `.` | 通路 | `none.png` |
| `P` | プレイヤー（1つのみ） | `play.png` |
| `F` | 食べ物 | `food.png` |
| `T` | 罠 | `trap.png` |

例：

```text
#####
#P..#
#.#F#
#..T#
#####
```

迷路ゲームでは3行3列以上のマップが必要です。行内に空白を入れないでください。空行は無視されます。

## 8. HTTP API

迷路ゲームのHTTPサーバーを開始すると、外部プログラムから盤面の取得や操作ができます。初期URLは`http://127.0.0.1:8000`です。

| メソッド | エンドポイント | 内容 |
|---|---|---|
| `GET` | `/` | API一覧を取得 |
| `GET` | `/state` | 現在の盤面とゲーム状態を取得 |
| `POST` | `/move?direction=up` | 上下左右へ移動 |
| `POST` | `/move_to?row=1&column=2` | 隣接する指定マスへ移動 |
| `POST` | `/reset` | マップを再読み込みしてリセット |
| `POST` | `/rewards?...` | 報酬設定を更新 |

移動方向には`up`、`down`、`left`、`right`を指定できます。移動APIを使うには「リモートプレイを許可」を有効にしてください。

## 10. トラブルシューティング

### Qラーニングから迷路ゲームへ接続できない

- 迷路ゲームのHTTPサーバーが起動中か確認してください。
- 両方のアプリでURLとポートが一致しているか確認してください。
- 迷路ゲーム側で「リモートプレイを許可」を有効にしてください。
- ポート`8000`を別のアプリが使用している場合は、両方のアプリで別のポートを指定してください。

### 学習結果が食べ物へ到達しない

エピソード数、各報酬、探索率、学習率を調整してください。また、初期エネルギー20と1エピソード100ステップ以内で食べ物へ到達できるマップか確認してください。

### 画像ファイルが見つからない

Python版のQラーニングは、迷路ゲーム側の`Images`フォルダーを参照します。上記のディレクトリ構成を保ったまま実行してください。
